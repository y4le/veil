This page is encrypted exactly like the one you came from. It opened anyway, because the key cached when you unlocked that page belongs to the whole build; unlocking one page unlocks every page in the same zone.

Why

Each build mints one master key. Every page in it is encrypted under that key with its own IV, and the browser caches the key under a name derived from the zone's id. This page found veil:v2:y4le-veil-demo:mk already populated and used it.

That is also why /vault/ still prompts: it was built separately, under its own id and passphrase, so nothing in this zone's cache can open it.

Redeploying the site mints a new master key, so this cached one stops working and you are asked again.
