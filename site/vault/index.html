What that proves, and what it does not

It proves the wall is real: the bytes on the wire for this route are ciphertext, and only the right passphrase turns them into this document.

It does not prove the content is secret. This page's plaintext is committed to the public repository, which is the point; you can compare the source against what the host serves and confirm that Veil did what it claims.

Veil protects a built artifact. A public source repository, an untrusted build pipeline, and a host that can rewrite the unlock shell are all outside what it can do.
